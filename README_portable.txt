实验软件便携版使用说明

1. 双击"实验软件.exe"启动。
2. 串口采集前，先编辑 config 目录里的 JSON 配置文件，确认波特率、寄存器地址等参数正确。
3. 如果 COM 口变了，可以在软件里直接点 Search COM 搜索可用串口，并临时切换，不用手改 JSON。
4. Modbus 页面支持"开始实时曲线采集"，采集时会弹出实时曲线窗口，边采集边显示。
5. Modbus 采集结果默认保存到 logs 目录。
6. PWM 分组测量：在"分组测量"页签输入 PWM（例如 500），点"开始测量"会把 PWM 通过 Modbus 06 写入配置中登记的寄存器；曲线稳定后录入总电流，点"结束测量"即可算出 M_y/M_x/M/θ。
7. 一组测完点"下一组"继续；全部测完点"导出表格"会把结果追加到当前 Excel 的 measurements sheet，与主数据共用一份 xlsx。
8. 实时曲线后台线程读串口，前台 Tk after 调度刷新，画布用 draw_idle()，长时间运行不卡顿。
9. 视频回填会读取 videos 目录中的视频，以及 logs 目录中的最新 Excel，再生成带 video_ocr 后缀的新文件。
10. 曲线绘制在"可靠数据与曲线"功能中，会读取 *_video_ocr.xlsx 并在 output 目录输出可靠数据 Excel 与曲线图。
11. output 目录用于后续导出结果文件。
12. 问题反馈：在"问题反馈"页签填写主题与正文（≥10 字符），点"发送"即可发到 koji3527@qq.com。首次使用前请在 config/email.json 填入发件 QQ 邮箱与授权码。限流 60 秒/封、20 封/天。

目录说明

- config: 配置文件
- logs: 采集得到的 Excel 日志
- videos: 待处理视频
- output: 后处理结果

说明

- 这个便携版不需要安装 Python。
- 如果串口设备没有返回数据，请先检查串口号、波特率、从站地址和接线。
- 邮件发送失败的常见原因：config/email.json 没填、授权码过期、QQ 邮箱未开启 SMTP 服务、网络无法连接 smtp.qq.com:465。
