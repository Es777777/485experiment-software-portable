实验软件便携版使用说明

一、启动方式

1. 解压便携版压缩包。
2. 双击“实验软件.exe”启动软件。
3. 首次运行前，建议先检查 `config/` 目录中的配置文件。

二、采集前准备

1. 根据设备实际情况修改 `config/` 下的 JSON 配置。
2. 确认串口号、波特率、校验位、停止位、从站地址和寄存器地址正确。
3. 如果现场串口变化，可以先启动软件，再使用 Search COM 搜索并切换可用串口。

三、PWM 分组测量流程

1. 进入 Modbus 页面。
2. 点击“开始实时曲线采集”，打开实时曲线窗口。
3. 在分组测量区域输入本组 PWM。
4. 直接点击“开始测量”。
5. 人工观察曲线稳定后，输入本组总电流。
6. 点击“结束测量”，软件会记录结束时间并计算本组平均合力。
7. 查看窗口中的历史记录，确认本组结果已经保存。
8. 点击“下一组”，清空 PWM 和总电流输入框，准备下一组。

按钮顺序说明

- 第一组开始前：不要先点“下一组”，先输入 PWM，然后点“开始测量”。
- 一组测量中：不要重复点“开始测量”。
- 一组完成后：先点“结束测量”，确认结果已经显示，再点“下一组”。
- “下一组”只是清空输入框并准备新一组，不会自动开始采集。
- 如果没有输入 PWM，就点“开始测量”，程序会提示先输入 PWM。
- 如果没有输入总电流，就点“结束测量”，程序会提示先输入总电流。

四、导出结果表

1. 所有分组测量结束后，点击“导出表格”。
2. 结果文件会保存到 `output/` 目录。
3. 导出文件名带日期时间，便于区分不同实验批次。
4. 表格前部是汇总信息，后部包含原始时间戳、原始合力和各通道原始值。

五、目录说明

- `config/`：配置文件目录
- `logs/`：采集日志和原始 Excel 日志
- `output/`：导出结果、后处理结果和图表
- `videos/`：待进行视频回填处理的视频文件

六、常见问题

1. 没有采到数据：检查串口号、波特率、从站地址和接线。
2. 数据值不正确：检查寄存器地址、数据类型、缩放系数和字节序设置。
3. 找不到导出结果：优先到 `output/` 目录中查找。

说明

- 这个便携版不需要安装 Python。
- 如果交给实验人员使用，建议整包分发，不要只单独发送 exe 文件。
