实验软件便携版使用说明

1. 双击“实验软件.exe”启动。
2. 串口采集前，先编辑 config 目录里的 JSON 配置文件，确认波特率、寄存器地址等参数正确。
3. 如果 COM 口变了，可以在软件里直接点 Search COM 搜索可用串口，并临时切换，不用手改 JSON。
4. Modbus 页面支持“开始实时曲线采集”，采集时会弹出实时曲线窗口，边采集边显示。
5. Modbus 采集结果默认保存到 logs 目录。
6. 视频回填会读取 videos 目录中的视频，以及 logs 目录中的最新 Excel，再生成带 video_ocr 后缀的新文件。
7. 曲线绘制在“可靠数据与曲线”功能中，会读取 *_video_ocr.xlsx 并在 output 目录输出可靠数据 Excel 与曲线图。
8. output 目录用于后续导出结果文件。

目录说明

- config: 配置文件
- logs: 采集得到的 Excel 日志
- videos: 待处理视频
- output: 后处理结果

说明

- 这个便携版不需要安装 Python。
- 如果串口设备没有返回数据，请先检查串口号、波特率、从站地址和接线。
