# Release notes — v1.0.3

## PWM Modbus 写

- 串口实时采集新增 PWM Modbus 写（功能码 06），输入数字按回车即可下发到 `config/logger_config.json` 里 `pwm.register` 指定的寄存器。
- 范围校验：写入值会被夹到 `pwm.min_value` ~ `pwm.max_value`，并通过 `parse_pwm_value` 在解析阶段就拦截越界。
- 写失败时会弹 `messagebox.showwarning`，并保留 `last_pwm_value` 以便 UI 显示最近一次结果，不会让脚本异常退出。

## PWM 进入主表

- 主 live data Excel sheet `data` 末尾新增 `pwm` 列，未下发 PWM 时为空字符串，下发后填入当前 PWM 字符串。
- `ExcelLogger.expected_headers` 动态包含 `pwm`，并通过 `poll_once` 注入行；无需改动现有 `data` sheet 数据。

## 统一 xlsx 多 sheet

- `write_measurement_workbook` 现在支持追加到现有 xlsx：保留 `data` 主表，删除旧的 `measurements` 后重建，保证两边数据一致。
- 导出按钮默认写入当前 session 的 `logger.workbook_path`（与 live data 同一个工作簿），无活动 live plot 时 fallback 到 `build_measurement_export_path`。

## 线程 / 刷新修复

- `LivePlotter._refresh_canvas` 改用 `self.fig.canvas.draw_idle()`，避免 `plt.pause(0.001)` 抢主线程。
- `main()` 把串口轮询放进 daemon thread，UI 走 Tk `after(50, _ui_tick)` 调度，主线程只 `plt.show()` 阻塞。
- `_ui_tick` 读取 `submit_live_row` 提交的最新一行并调用 `add_point`，再异步重绘画布。
- 退出时 `request_quit()` 取消 after、`stop_event` 唤醒 sleep，daemon 线程最迟 1 秒内退出。

## 问题反馈邮件

- 新增 `scripts/email_feedback.py`，通过 QQ SMTP（`smtp.qq.com:465` SSL）把反馈发送到 `koji3527@qq.com`。
- 启动器新增 "问题反馈" tab，填写主题、回信邮箱（可选）、描述后点 "发送反馈"。
- 限流：连续发送间隔不小于 60 秒，单日最多 20 封；状态写入 `config/email_feedback_state.json`（已 gitignore），跨重启持续生效；新一天 0 点计数自动清零。
- 凭据模板：`config/email.json.example`（已加入仓库），实际凭据写入 `config/email.json`（已 gitignore）；可在 UI 内点 "创建邮箱配置模板" 按钮生成。
- 发送成功后自动禁用按钮 60 秒，状态栏显示倒计时；超过 20 封/日后按钮永久禁用并提示明日重试。
