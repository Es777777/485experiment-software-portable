# Release notes — v1.0.4

## 双 COM 串口拆分

- `scripts/serial_logger_with_plot.py` 新增 `PwmSerialConfig` dataclass，承载 `port/baudrate/bytesize/parity/stopbits/timeout`
- `PwmConfig` 新增 `serial: Optional[PwmSerialConfig]` 字段；`is_configured()` 在 `register` 或 `serial` 任一存在时返回 True（向后兼容）
- `main()` 打开第二根串口（`pwm_client`），`finally` 中按开顺序反向关闭
- `write_pwm_value` 优先用 `_pwm_serial_client`（独立 PWM 客户端），未配置时回退到 `_serial_client`（485 客户端，兼容旧设备）
- CLI 新增 `--pwm-port` 参数，`main()` 用 `replace(app_config.pwm, serial=PwmSerialConfig(...))` 注入

## 启动器 UI

- `app_launcher.py` 新增 `pwm_port_var`、`pwm_port_combo`，`_build_modbus_tab` 在 "485 串口" 行下方加一行 "PWM 串口"
- `refresh_serial_ports(target)` / `_resolve_port_override` / `_load_config_port` / `use_config_port` 全部按 `target` 字典分发（modbus/raw/pwm）
- `start_modbus_live_plot` 把 `--pwm-port` 透传给被拉起的子进程

## 配置文件

- `config/logger_config.json` 的 `pwm` 块新增 `port/baudrate/bytesize/parity/stopbits/timeout` 字段（默认 COM5/9600/8/N/1/1.0）

## 测试

- `tests/test_serial_logger_with_plot.py` 新增 4 个测试：
  - `PwmSerialConfig` 字符串端口解析
  - `PwmSerialConfig` 对象端口解析（含 `device/baudrate/parity/stopbits` 字段）
  - `write_pwm_value` 使用独立 PWM 客户端（不调 485 客户端）
  - `write_pwm_value` 在 PWM 客户端失败时弹 `messagebox.showwarning`
