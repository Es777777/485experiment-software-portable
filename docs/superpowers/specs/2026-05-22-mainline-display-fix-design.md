# 主线普通版显示问题修复与重新发布设计

## 目标

回到主线普通版，系统修复主窗口与实时曲线/分组测量窗口中“文字堆叠、挤压、无法正常显示”的问题，并基于修复后的主线重新生成便携版、同步 GitHub 代码并更新 Release。

本轮重点是“显示稳定性与布局自适应”，不是继续增加新视觉元素。

## 背景

当前主线已经完成：

- 主窗口工作台化改造
- 分组测量结果卡片、数学公式区、历史区和导出结果增强
- 普通版便携包与 `v1.0.1` Release

但用户反馈当前主线仍存在新的可用性问题：

- 多处中文文本堆叠
- 文字与按钮或输入框互相挤压
- 有些区域无法正常显示

用户要求这次要把问题修完整，并且修复范围不仅限于源码，还包括：

- 便携版
- GitHub 上的代码
- GitHub Release 附件

用户已确认：

- 先修主线普通版
- 主窗口和实时曲线窗口都一起处理
- 北航特供版暂时不作为本轮主目标扩散

## 设计结论

### 1. 这次以“布局自适应修复”为主，不再继续扩 UI 密度

这轮不继续叠加新卡片、新文案、新装饰，而是把当前已经存在的内容稳定地摆对位置。

优先级如下：

1. 先解决堆叠、截断、互相覆盖
2. 再保证在常见桌面缩放下可读
3. 最后再保留现有视觉层次

也就是说，本轮是“稳住布局”，不是“继续堆设计”。

### 2. 主窗口修复策略：三层结构保留，但全部改成弹性布局

主窗口继续保留：

- 顶部品牌区
- 中部工作区
- 底部状态/日志区

但每一层都要做抗挤压处理：

- 标题、副标题、署名增加合理换行宽度。
- 快捷入口区允许在宽度不足时更自然分布，不靠死宽度强排一行。
- `Notebook` 顶部说明文本统一控制 `wraplength`。
- 各 tab 内表单项、组合框、路径输入框配置列权重，允许拉伸。
- 状态徽标和状态说明改成弹性布局，不再互相抢占一行宽度。
- 日志区保持可扩展，优先吃掉多余空间。

### 3. 实时曲线窗口修复策略：拆开高密度横排区域

实时曲线窗口中最容易出问题的是顶部与分组测量区的横向挤压，因此要优先做结构拆分：

- `PWM`、`总电流` 输入区与操作按钮区不再强制塞在一条水平带里。
- 状态、摘要、上下文提示文字不与公式区共抢同一行。
- 结果卡片、公式区、历史区拆成更明确的上下分层。

目标是：

- 中文字体变宽时不撞
- Windows 125%/150% 缩放下不炸
- 内容变长时优先换行，不优先互相覆盖

### 4. 数学公式区作为独立展示块处理

公式区已经是当前主线的重要功能，但它本身也容易造成布局拥挤。

因此本轮要求：

- 公式画布有独立空间，不再和状态/摘要硬抢横向宽度。
- 调整 figure 尺寸、边距和周边容器布局，使其在常见窗口尺寸下稳定显示。
- 公式显示优先追求“稳定可见”，不是一味扩大。

### 5. 所有长文案都必须支持换行和宽度约束

本轮系统性规则：

- 说明文字、上下文提示、署名、状态说明、长路径说明都必须有换行策略。
- 不允许依赖“默认字体刚好够宽”这种偶然条件。
- 任何一段长文本都必须满足：窗口稍微缩小后仍优先换行，而不是把相邻控件顶坏。

### 6. 修复范围覆盖源码、便携版与 GitHub 发布物

本轮不是只改本地源码。修复完成后必须同步到三处：

- 源码主线
- 普通版便携包
- GitHub Release

要求最终一致：

- 本地源码运行效果
- 桌面便携版运行效果
- GitHub Release 下载后的效果

三者必须代表同一轮修复结果。

### 7. 北航特供版不作为这轮主线发布目标

虽然仓库中已经有北航特供版相关工作，但本轮主目标明确是修复普通版主线显示问题。

因此：

- 主线修复完成并重新发布的是普通版
- 不把北航特供版的显示问题修复混进本轮主线发布判断里
- 如需后续同步北航特供版显示修复，可在主线稳定后再单独处理

## 受影响文件范围

### 主窗口

- `app_launcher.py`
  - 品牌区换行
  - 快捷入口布局
  - `Notebook` 说明文字与表单弹性布局
  - 状态条与日志区伸缩关系

### 实时曲线/分组测量窗口

- `scripts/serial_logger_with_plot.py`
  - 输入区与按钮区拆分
  - 结果区、提示区、公式区、历史区的分层与换行控制
  - 公式画布尺寸与容器布局调整

### 测试与打包

- `tests/test_app_launcher.py`
  - 新增长文本/布局辅助函数测试
- `tests/test_serial_logger_with_plot.py`
  - 新增长提示文本、布局辅助函数或显示状态相关测试
- `build_release.ps1`
  - 如需调整便携版内资源或说明文件内容，同步更新

### 文档与发布

- `README.md`
- `README_portable.txt`
- `CHANGELOG.md`
- `docs/release-notes/...`

必要时同步补充“显示修复”发布说明。

## 验证要求

### 自动验证

- 主窗口和实时曲线相关测试全部通过。
- 文档与 release 元数据测试继续通过。
- 脚本入口和启动器仍能正常启动。

### 人工验证

- 主窗口中品牌区、副标题、快捷入口、状态条不发生明显重叠。
- `Notebook` 各页中长文案、路径输入和按钮区不互相覆盖。
- 分组测量区输入项、按钮、状态提示、结果卡片、公式区、历史区都能正常显示。
- 便携版运行后的界面与源码运行结果一致。

### 发布验证

- 新便携包成功生成。
- 桌面便携版目录更新为修复后版本。
- GitHub 代码和 Release 附件同步到这轮修复结果。

## 不做事项

- 不继续增加新的大块 UI 功能。
- 不重做信息架构。
- 不把北航特供版一并纳入这轮主线发布判断。
- 不牺牲普通版逻辑正确性去只追求界面好看。

## 完成标准

完成后，普通版主线应满足：

- 主窗口和实时曲线窗口无明显字堆叠和覆盖问题。
- 常见桌面缩放下仍能正常阅读和操作。
- 重新打包后的便携版与源码表现一致。
- GitHub 代码、Release 附件和桌面便携版三者同步更新到同一修复结果。
