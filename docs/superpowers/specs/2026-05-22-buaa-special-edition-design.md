# 北航特供版便携包设计

## 目标

在不改动普通版行为的前提下，额外生成一个“北航特供版”便携包，用于北航场景下的传感器量程口径。

该版本的唯一核心行为差异是：

- `T1`、`T2`、`T3` 全部按原结果的 `1/3` 显示与导出
- `M_y`、`M_x`、`M`、`theta` 全部基于缩放后的 `T1/T2/T3` 重算

除此之外，普通版和北航特供版在界面、流程、导出结构和便携版布局上保持一致。

## 背景

当前项目已经完成：

- 主窗口 UI 打磨
- 实时曲线与分组测量面板增强
- 数学公式展示与结果卡片
- Excel 导出列与界面关键结果一致
- 普通版便携包 `v1.0.1`

用户现在要求新增一个**单独的便携版**，命名为“北航特供版”，其用途是适配北航使用的传感器最大量程口径。

用户明确确认：

- 不要改普通版
- 不要增加额外切换开关
- 单独产出一个北航特供版便携包
- 采用 `B` 规则：`T1/T2/T3` 缩放后，`M_y / M_x / M / theta` 也全部跟着一起按缩放后的值重算

## 设计结论

### 1. 普通版与北航特供版并存

本次不在现有软件里增加“北航模式”开关，而是保留两套独立分发物：

- 普通版：保持当前行为不变
- 北航特供版：仅针对 `T1/T2/T3` 及其衍生力矩结果使用 `1/3` 口径

这样可以避免误用，也不会破坏已经交付或已经验证过的普通版。

### 2. 北航特供版的数值规则

分组测量结束后，当前逻辑会先得到该组的三路组内平均值：

- `T1_raw`
- `T2_raw`
- `T3_raw`

北航特供版中，在进入结果展示和导出之前，统一先做：

- `T1_buaa = T1_raw / 3`
- `T2_buaa = T2_raw / 3`
- `T3_buaa = T3_raw / 3`

然后所有力矩结果基于缩放后的值重算：

- `M_y = 1/2*T1_buaa + 1/2*T2_buaa - T3_buaa`
- `M_x = sqrt(3)/2*(T2_buaa - T1_buaa)`
- `M = sqrt(M_x^2 + M_y^2)`
- `theta = atan2(M_x, M_y)`

### 3. 不缩放的字段

以下字段保持原样，不参与 `1/3`：

- `总电流`
- `平均合力`
- 原始时间戳
- 原始合力
- 原始 `ch1/ch2/ch3` 采样值

设计理由：

- 用户指出 `1/3` 与传感器最大量程有关，影响的是 `T1/T2/T3` 口径
- 原始采样列应保留原始测量值，便于追溯
- 这样“汇总结果是北航口径，原始列仍是原始采样”边界最清晰

### 4. 北航特供版中的界面表现

北航特供版中，以下界面结果全部显示北航口径：

- 结果卡片中的 `T1/T2/T3`
- 数学公式区中的 `M_y / M_x / M / theta`
- 上下文结果摘要里涉及 `T1/T2/T3` 的内容

普通版界面完全不变。

### 5. 北航特供版中的 Excel 导出表现

北航特供版的导出表中：

- 汇总列中的 `T1平均值/T2平均值/T3平均值/M_y/M_x/M/theta(度)` 使用北航口径
- `总电流`、`合力平均值` 保持普通口径
- 后部原始列仍保留原始时间戳、原始合力和原始 `ch1/ch2/ch3`

这意味着：

- 汇总列 = 北航结果口径
- 原始列 = 原始采样口径

### 6. 北航特供版的命名与分发

北航特供版作为单独产物发布，命名建议如下：

- 桌面目录：`实验软件_北航特供版_YYYYMMDD`
- 便携版 zip：`485experiment-software-portable-buaa-v1.0.1-YYYYMMDD.zip`

软件内部也增加轻量区分信息，例如：

- `北航特供版`
- 或 `BUAA Edition`

要求是：用户打开目录、压缩包和软件窗口时，都能一眼看出这不是普通版。

### 7. 轻量提示文案

为避免使用者误解，北航特供版应增加轻量提示，说明：

- `T1/T2/T3` 与由其推导的力矩结果已按 `1/3` 系数换算

该提示可以放在：

- 北航特供版 README
- 启动窗口副标题或状态区
- 测量窗口底部小字说明

但普通版文案不作变更。

## 受影响范围

### 代码层

- `scripts/serial_logger_with_plot.py`
  - 新增或注入北航版缩放口径逻辑
  - 更新界面展示和导出使用的 `T1/T2/T3` 与力矩结果
- `app_launcher.py`
  - 北航特供版窗口标题/副标题或说明文案的区分显示

### 测试层

- `tests/test_serial_logger_with_plot.py`
  - 增加北航版缩放和导出列测试
- 如主窗口文案存在辅助函数，也应加对应测试

### 打包与文档层

- 北航特供版专用的便携版说明文件或专用文案
- 北航特供版打包输出命名逻辑
- 必要时补充北航特供版 release note

## 验证要求

### 自动验证

- 普通版现有测试继续通过
- 北航特供版新增测试验证：
  - `T1/T2/T3 = 原值 / 3`
  - `M_y/M_x/M/theta` 基于缩放后的 `T1/T2/T3` 重算
  - 北航特供版导出汇总列与界面一致
  - 原始列保持原始值不变

### 人工验证

- 北航特供版启动后能明显识别其不是普通版
- 分组测量结果区中 `T1/T2/T3` 和 `M` 相关结果显示为北航口径
- 导出 Excel 中汇总列与界面口径一致，原始列保持原始采样值

## 不做事项

- 不改普通版计算逻辑
- 不在普通版里增加模式切换开关
- 不修改总电流、平均合力和原始采样值口径
- 不改变北航特供版之外的其他分发物命名

## 完成标准

完成后，应同时存在：

- 行为不变的普通版便携包
- 单独命名、单独可识别的北航特供版便携包

并且北航特供版满足：

- `T1/T2/T3` 为原结果 `1/3`
- `M_y/M_x/M/theta` 基于缩放后的 `T1/T2/T3` 重算
- Excel 汇总列与界面结果一致
- 原始列保持原始采样数据
