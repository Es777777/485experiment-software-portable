# PWM 分组测量与导出设计

## 目标读者

- 需要在当前桌面实验软件源码上实现 PWM 分组测量流程的开发者。
- 需要确认实验测量步骤、结果展示和导出格式是否符合现场操作习惯的使用者。

## 背景

当前实验软件已经支持 Modbus 实时曲线采集，并在 `scripts/serial_logger_with_plot.py` 中完成串口轮询、实时曲线显示、去皮和合力计算。现状仍然缺少实验操作所需的分组测量流程：

1. 无法在测量时为每组输入 PWM 并记录开始时间。
2. 无法在人工判断稳定后输入总电流并记录结束时间。
3. 无法只对某一组开始到结束区间内的合力数据求平均值。
4. 无法连续记录多组 PWM 的结果并在结束后一次性导出实验表格。
5. 当前实时曲线版本的合力展示包含较慢的显示逻辑，而本次测量统计需要恢复为更接近原始实时采样节奏的合力口径。

本次设计仅覆盖实时曲线采集路径，不改动普通 Modbus 采集、原始串口采集、视频回填和可靠数据后处理功能。

## 设计结论

### 1. 在现有实时曲线窗口内增加分组测量流程

- 不新建独立工具页，也不把测量状态放回启动器主窗口。
- 用户仍从 `app_launcher.py` 的“开始实时曲线采集”进入实验流程。
- 在实时曲线窗口内部新增一块“分组测量”操作区，包含：`PWM` 输入框、`开始测量`、`总电流` 输入框、`结束测量`、`下一组`、`导出表格`。
- 这样用户在观察曲线稳定状态时即可直接完成每组测量操作，避免多窗口切换。

### 2. 每组测量按开始/结束区间统计

- 点击 `开始测量` 时：校验 PWM 已填写，记录本组 PWM 与北京时间开始时间，清空当前组样本缓存，并开始记录后续样本。
- 点击 `结束测量` 时：校验当前组已经开始且总电流已填写，记录北京时间结束时间，只对本组开始到结束之间的有效合力样本计算简单平均值，并把本组结果加入已完成列表。
- 未处于本组时间区间内的采样，不参与本组合力平均值计算。

### 3. 测量统计使用原始实时采样口径的合力

- 当前图窗仍可保留已有实时显示与辅助文本逻辑。
- 但用于“分组测量平均值”的合力样本，必须使用原始实时采样节奏下的合力值，不通过上一秒平均或额外慢速平滑再计算。
- 合力定义仍为 `total_force = ch1 + ch2 + ch3`，仅在三个通道值都有效时产生。
- 这样既保留现有可视化效果，又把实验统计速度恢复到更接近原来版本的响应方式。

### 4. 连续多组测量，最后一次性导出

- 一次实时采集中允许连续记录多组 PWM。
- 每组结束后，界面立即展示本组结果。
- 点击 `下一组` 时，只清空当前组 PWM、总电流、开始/结束状态和当前组缓存，保留之前已完成的所有组结果。
- 点击 `导出表格` 时，将当前实验会话中所有已完成组一次性写入一个 Excel 文件；若没有任何完成组，则提示不能导出。

### 5. 导出格式采用单表、一组一行、原始数据列追加到后部

- 默认主表列顺序为：`序号`、`PWM`、`开始时间(北京时间)`、`结束时间(北京时间)`、`总电流`、`合力平均值`。
- 每一组结果占一行。
- 该行后方继续追加本组区间内的原始数据列，至少包括：`原始时间戳_1`、`原始合力_1`、`原始时间戳_2`、`原始合力_2`，依此类推。
- 如果三个通道原始值在当前实现中易于一并保留，则继续在后部追加 `原始ch1_n`、`原始ch2_n`、`原始ch3_n` 列。
- 本次设计优先保证单文件、单工作表可直接查看；不拆第二张“原始数据”工作表。

## 组件与改动范围

### `scripts/serial_logger_with_plot.py`

该文件承担主要改动。

- 扩展实时图窗逻辑，增加分组测量会话状态：当前组 PWM、开始时间、结束时间、总电流、原始时间序列、原始通道值序列、原始合力样本序列、已完成组结果列表。
- 增加用于界面控件的输入区、按钮和结果预览区域。
- 将“显示用统计”与“测量导出用统计”区分开：显示逻辑沿用图窗现有结构，导出逻辑改为直接基于原始实时合力样本。
- 增加 Excel 导出函数，负责根据所有已完成组动态展开原始数据列并写入 `output`。
- 为了便于测试，把以下逻辑抽成独立函数或小方法：开始一组测量、结束一组测量、记录当前组样本、计算当前组合力平均值、重置到下一组、生成导出文件名、生成动态表头与导出行。

### `app_launcher.py`

- 启动入口仍然保持“开始实时曲线采集”。
- 如有必要，仅更新说明文字，让用户知道实时窗口现在支持 PWM 分组测量、总电流录入和导出。
- 不新增独立测量工具命令，也不新增新的标签页。

### `tests/test_serial_logger_with_plot.py`

- 为分组测量状态流转、平均值统计、下一组重置和导出格式增加失败测试。
- 保留并继续验证当前去皮、上一秒平均值、合力计算等已有行为。

## 数据流

1. `poll_once()` 继续以当前实时采样频率读取通道原始值。
2. `LivePlotter.add_point()` 接收当前时刻和通道原始值。
3. 图窗仍按现有逻辑进行去皮、合力计算和实时显示更新。
4. 若当前组处于“测量中”状态，则把本次原始时间戳、原始通道值和原始合力样本记录到当前组缓存。
5. 点击 `结束测量` 时，从当前组缓存直接计算平均合力并固化为一条结果记录。
6. 点击 `导出表格` 时，遍历所有已完成组，生成单表 Excel 并写入 `output` 目录。

## 界面行为

- 新增“分组测量”操作区，位置可在图窗下方或侧边，但必须与实时曲线同窗显示。
- 结果预览至少显示：当前组状态、当前组 PWM、开始时间、结束时间、总电流、合力平均值、已完成组数。
- 每组结束后，把结果加入结果列表或文本区，用户可立即确认是否记录成功。
- `下一组` 只重置当前组状态，不清除历史组结果。
- 若存在未导出的已完成组，关闭图窗前给出提示，让用户先导出或确认放弃。

## 边界与异常处理

- 测量中禁止再次点击 `开始测量`。
- 未开始时禁止点击 `结束测量`。
- 当前组未结束时禁止进入 `下一组`。
- 当前组结束时如果没有任何有效合力样本，则提示失败，不写入结果。
- 若总电流输入无法转换为数字，则不允许结束本组。
- 如果 PWM 为空，则不允许开始本组。
- 时间全部按本机北京时间直接记录，不做额外时区转换。
- 导出文件名必须带日期时间，例如 `measurement_results_20260508_154530.xlsx`。
- 动态原始数据列长度以“本次所有组里原始样本最多的一组”为准；较短组的空位留空。

## 测试策略

遵循 TDD：先写失败测试，再写最小实现。

### 单元测试重点

- 开始测量后只记录本组时间区间内的样本。
- 结束测量时合力平均值只由该区间样本计算。
- `下一组` 会清空当前组状态但保留已完成组结果。
- 没有有效样本时不能生成结果行。
- 导出表头包含基础列和动态原始数据列。
- 导出文件名包含日期时间。

### 手工验证重点

- 实时曲线窗口可以输入 PWM、点击开始、输入总电流、点击结束。
- 结束后界面立即显示本组 PWM、时间、电流和平均合力。
- 点击下一组后，可以继续记录下一组而不丢失之前结果。
- 点击导出后，在 `output` 中生成带日期时间的 Excel 文件。
- 导出表格前几列为汇总，后续列为该组原始时间戳和原始合力序列。

## 不做事项

- 不修改普通采集 Excel 文件格式。
- 不修改视频回填与后处理逻辑。
- 不新增独立测量工具页。
- 不在本次迭代中加入数据库、云同步或多文件导出等扩展项。

## 实施建议

- 以 `实验软件 - 副本` 作为主修改目录，它与桌面便携版构建产物一致。
- 先补分组测量失败测试，再实现状态管理和导出逻辑，最后做打包验证与 GitHub 提交。
